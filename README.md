# Kuji (제일복권)

일본 이찌방쿠지(一番くじ) 스타일 박스 추첨 시뮬레이터.
유한 박스에서 제비를 뽑아 등급별 상품을 모으는 **수집/완주 경험**이 목적.
사행성 강화나 당첨 확률 향상이 아님.

## 1. 플레이

- (작성 예정) 박스 선택 → 제비 뽑기 → 등급 / 상품 공개 → 박스 진척도 갱신.

## 2. 조작

- 터치 / 클릭 / 키보드.

## 3. 메커닉

- (`docs/01_spec.md` 확정 후 정리.)

## 4. 개발

- ES Modules 직접 사용. 빌드 도구 없음.
- 정적 dev 서버에서 `index.html` 진입.
- 테스트는 `tests/test.html` 브라우저로 열기.
