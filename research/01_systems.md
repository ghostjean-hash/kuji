## 1. 일본 쿠지 시스템 메커닉 카테고리 분류

쿠지(クジ)는 "추첨식 상품 판매". 일본에서는 1회당 정해진 가격을 지불하면 미리 봉인된 등급 중 하나를 제비뽑기로 받는 형태가 주류다. 거의 모든 카테고리가 "ハズレなし(꽝 없음)"를 기본 전제로 하므로, 메커닉 차이는 추첨 방식 / 박스 운용 / Last One·Double Chance 룰에서 발생한다.

| 카테고리 ID | 일본어 | 한국어 | 추첨 방식 | 매장 형태 | 비복원 박스 |
|---|---|---|---|---|---|
| `ichiban_kuji` | 一番くじ | 이찌방쿠지 | 매장 비복원 박스 + 온라인 (一番くじONLINE) | 편의점(세븐, 로손) / 서점 / 호비숍 / 공식숍 / 온라인 | 예 |
| `sega_lucky` | セガ ラッキーくじ | SEGA 럭키 쿠지 | 매장 비복원 박스 + 온라인 (SEGA ラッキーくじオンライン) | 편의점 / 호비숍 / 게임센터 / 온라인 | 예 |
| `happy_kuji` | Happyくじ | Happy 쿠지 | 매장 비복원 박스 | 편의점(세븐 중심), 이토요카도, 유메타운 | 예 |
| `furyu_kuji` | フリューくじ (구 みんなのくじ) | 후류 쿠지 (구 모두의 쿠지) | 매장 비복원 박스 | 편의점 / 호비숍 / 캐릭터 그라파 (キャラ広場) | 예 |
| `kotobukiya_kuji` | コトブキヤくじ | 코토부키야 쿠지 | 온라인 단발 추첨 (단건 / 10연 / 30연 세트) | 코토부키야 온라인 전용 | 운영 추정. 가시적 잔여 카운터 없음 |
| `taito_kuji` | タイトーくじ (구 タイトーくじ本舗) | 타이토 쿠지 | 매장 비복원 박스 + 온라인 (タイくじオンライン) | 편의점 / 호비숍 / 게임센터(타이토 스테이션) / 온라인 | 예 |
| `lawson_loppi` | ローソン エンタメくじ / Loppi 한정 쿠지 | 로손 엔터테인먼트 쿠지 | 매장 비복원 박스 (Loppi 단말 발권 + 점원 제비) | 로손 / Loppi 단말 / HMV | 예 |
| `bandai_online` | バンプレくじ プレミアム / 一番くじONLINE | BANDAI 온라인 쿠지 | 온라인 디지털 추첨 | 온라인 (PC/모바일) | 예 (잔여 카운터 표시) |
| `amusement_ichiban` | アミューズメント一番くじ | 어뮤즈먼트 이찌방쿠지 | 게임센터 비복원 박스 (점포 한정) | 게임센터 / 반다이남코 어뮤즈먼트 시설 | 예 |
| `cafe_collab_kuji` | 콜라보 카페 한정 쿠지 / 굿즈 추첨 | 카페 콜라보 쿠지 | 카페 단발 추첨 또는 입장 특전 | 카페 매장 한정 | 형태별 상이 |

추가 메모: "스마호 쿠지" / "앱 가챠 쿠지"는 캐릭터 가챠 게임의 부속 시스템으로 별도 카테고리. 본 시뮬레이터의 실물 상품 콘셉트와는 다른 도메인이라 본 조사 범위에서 보류한다.

## 2. 카테고리별 대표 브랜드 / 운영사 / 매장 형태

### 2.1. 一番くじ (이찌방쿠지)

- 운영사: BANDAI SPIRITS (BANPRESTO 사업)
- 매장: 세븐 일레븐, 이토요카도, 유메타운, 로손, 패밀리마트 일부, 서점 (BOOKOFF, 츠타야), 호비숍 (Animate, Kotobukiya 매장 등), 공식 一番くじ ショップ, 一番くじONLINE (온라인)
- 활발도: 압도적. 월 평균 5~10개 신작 발매. IP 라인업이 가장 풍부 (ONE PIECE, ドラゴンボール, 鬼滅の刃, 呪術廻戦, ポケモン, HUNTER×HUNTER, たまごっち 등)

### 2.2. セガ ラッキーくじ (SEGA 럭키 쿠지)

- 운영사: 株式会社セガ (SEGA, 구 SEGA Interactive 프라이즈 부문)
- 매장: 세가 어뮤즈먼트 시설 (GiGO 등), 편의점 (특정 회차), 호비숍, 「セガ ラッキーくじオンライン」(온라인)
- 활발도: 매우 활발. 온라인 버전이 항시 4~6개 동시 진행. IP는 呪術廻戦, 名探偵コナン, ラブライブ!, 東京リベンジャーズ, 幽☆遊☆白書, 忍たま乱太郎 등 애니메이션 중심.

### 2.3. Happyくじ

- 운영사: 株式会社サニーサイドアップ 등 (PIXAR / Disney 라이선스 거래 중심)
- 매장: 세븐 일레븐, 이토요카도, 유메타운
- 활발도: 분기 페이스. PIXAR / Disney / Sanrio / 산리오 콜라보 라인이 강함.

### 2.4. フリューくじ (구 みんなのくじ)

- 운영사: フリュー株式会社. 2025년 3월부터 「みんなのくじ」를 「フリューくじ」로 명칭 변경.
- 매장: 편의점 (로손/패밀리마트 중심), キャラ広場 (캐릭터 그라파 - 후류 운영 캐릭터 굿즈샵)
- 활발도: 매월 1~3건. 初音ミク, 忍たま乱太郎, 刀剣乱舞ONLINE 등 여성 / 코어 팬 IP에 강함.

### 2.5. コトブキヤくじ

- 운영사: 株式会社 壽屋 (KOTOBUKIYA)
- 매장: コトブキヤくじ 공식 온라인 사이트 한정 (`kuji.kotobukiya.co.jp`)
- 활발도: 월 2~4건. アイドルマスター 시리즈, 創彩少女庭園, メガミデバイス, 独립 IP 한정에 특화.
- 특이점: 1연 / 10연 / 30연 단위로 구매. 30연 구매 시 S賞 1개 확정 (사실상 가챠적 천장).

### 2.6. タイトーくじ (タイトーくじ本舗)

- 운영사: 株式会社タイトー
- 매장: 편의점, 호비숍, 타이토 스테이션, 「タイくじオンライン」(온라인 - タイクレ 연동)
- 활발도: 월 2~4건. 게임 IP / 애니 IP 혼합.

### 2.7. ローソン エンタメくじ / @Loppi · HMV 한정 쿠지

- 운영사: 株式会社ローソンエンタテインメント (HMV 사이트 운영) + 라이선스 보유사
- 매장: 로손, @Loppi 단말, HMV 온라인
- 활발도: 일정하지 않음. 콜라보 베이스로 비정기. 鬼滅の刃, hololive, 신화 / 보컬로이드 콜라보 굿즈 사례 다수.

### 2.8. 一番くじONLINE (一番くじ 온라인 디지털)

- 운영사: BANDAI SPIRITS
- 매장: `online.1kuji.com` 단일
- 메커닉 차이: 매장 박스 비복원과 동일 잔여 룰 (잔여 카운터 표시), 다만 디지털 즉시 추첨, Double Chance가 구매 후 화면 즉시 도전 형식.
- 활발도: 매장 발매와 거의 동시 또는 며칠 후 온라인 오픈. 기존 매장형의 디지털 미러로 분류 가능.

### 2.9. アミューズメント一番くじ

- 운영사: BANDAI SPIRITS / 반다이남코 어뮤즈먼트
- 매장: 게임센터 / 반다이남코 어뮤즈먼트 시설 한정
- 활발도: 분기 1~2건. 고품질 프라이즈 피규어 중심 (`SUPER MASTER STARS PIECE` 등).

### 2.10. 콜라보 카페 한정 쿠지

- 운영사: 카페 운영사 (THE GUEST cafe&diner, ufotable cafe, animate cafe 등)
- 매장: 콜라보 카페 매장
- 메커닉: 입장 특전 또는 음료 1잔당 1회 등 결합 룰. "쿠지"라기보다는 "랜덤 굿즈 동봉" 형태에 가까움.
- 시뮬레이터 적합성: 낮음. 박스 비복원 / 등급 구조가 매장형보다 단순.

## 3. 인기 순위와 측정 기준

### 3.1. 측정 기준 (정성 + 정량 혼합)

| 기준 | 측정 방법 | 한계 |
|---|---|---|
| 발매 빈도 | 공식 사이트의 월별 라인업 카운트 (1kuji.com, sega.jp, h-kuji.com 등) | 일부 사이트는 과거 캠페인 잔존, 액티브 분간 어려움 |
| 매장 매진 속도 | 발매 당일 완판 보고, 재판 빈도, X(Twitter)에서 "ロット買い" / "ラストワン" 화제성 | 정량화 불가. 점포 입고 분량 차이 큼 |
| SNS 언급 | X 검색 결과 노출, 공식 계정 팔로워 (예: 一番くじ BANDAI SPIRITS @ichibanKUJI) | 봇 / 리셀러 트래픽 포함 |
| IP 파워 | 협업 IP의 최신 화제성 (애니 방영 중, 영화 개봉 등) | 일시적 변동 큼 |
| 매출 추정 | BANDAI SPIRITS 결산 자료 (전체 매출 1,161억엔 / 2021년) | 一番くじ 단독 매출 비공개. 카테고리 단독 분리 데이터 부재 |

데이터 부재 명시:
- 각 카테고리별 시장 점유율 정량 데이터 부재 (공시 자료 없음)
- フリューくじ, コトブキヤくじ, タイトーくじ의 연간 발매 회수 비교 데이터 부재 (각 사이트 발매 캘린더 수동 집계 외 방법 없음)
- 매진 속도 정량 비교 자료 부재. SNS 화제성에서 一番くじ가 압도적으로 많이 보이는 정성 관찰만 가능.

### 3.2. 인기 순위 (현재 시장 활발도 + 인지도 기준)

| 순위 | 카테고리 ID | 한국어명 | 근거 요약 |
|---|---|---|---|
| 1 | `ichiban_kuji` | 이찌방쿠지 | 압도적. 월 5~10건 발매, 메이저 IP 거의 독점 (ONE PIECE, DRAGONBALL, 鬼滅の刃, ポケモン), 편의점 전국 유통, 공식 X 팔로워 50만+, 검색 트렌드 1위 고정. |
| 2 | `sega_lucky` | SEGA 럭키 쿠지 | 온라인 동시 4~6건 진행. 呪術廻戦 / 名探偵コナン / ラブライブ! 등 애니 코어 IP. 게임센터 유통도 보유. |
| 3 | `happy_kuji` | Happy 쿠지 | PIXAR / Disney / Sanrio 라이선스의 대형 라인. 분기 발매지만 임팩트 큼. 세븐 일레븐 전국 유통. |
| 4 | `kotobukiya_kuji` | 코토부키야 쿠지 | 온라인 한정이지만 30연 S賞 확정 메커닉이 시뮬레이터로 흥미로운 차별점. アイドルマスター 시리즈와 코토부키야 자체 IP (創彩少女庭園 등) 코어 팬덤 강함. |
| 5 | `furyu_kuji` | 후류 쿠지 (구 みんなのくじ) | 매월 1~3건 발매. 初音ミク / 刀剣乱舞 등 여성 / 보컬로이드 코어 팬 라인업. キャラ広場 자체 채널 보유. |

순위 6위 이하 (참고):
- 6위 권: タイトーくじ (편의점 발매도 있으나 노출도가 SEGA보다 낮음)
- 7위 권: 一番くじONLINE은 一番くじ의 디지털 채널이라 별도 순위 부여 보류. 시뮬레이터 관점에서는 一番くじ와 함께 모듈화 가능.
- 8위 이하: ローソン エンタメくじ, アミューズメント一番くじ, 콜라보 카페 쿠지는 비정기 / 점포 한정 비중이 커서 독립 시뮬레이터화 우선순위 낮음.

### 3.3. 한계 / 데이터 부재 명시

- 본 순위는 2026-05-02 시점 WebSearch 결과 기반 정성 판단을 포함한다. 공식 매출 데이터는 비공개.
- "발매 빈도" 카운트는 공식 사이트 캘린더의 진행 중 / 최근 종료 라인업을 합산한 추정치다.
- SEGA와 一番くじ 사이의 실제 매출 격차는 공시 부재로 추정 불가. 본 순위는 "사용자 노출도 + IP 메이저성"으로 판단했음.

## 5. 시뮬레이터 후보 추천 (참고)

[의견] RPG 기획자가 PWA로 1개씩 시뮬레이터를 만든다면 메커닉 차별화가 분명한 다음 5개를 우선 후보로 추천한다.

1. `ichiban_kuji` - 박스 비복원 + Last One + Double Chance의 표준 룰. 모든 시뮬레이터의 모체 모듈로 적합.
2. `sega_lucky` - W럭키賞 (구매 시점 응모) 룰을 별도 모듈로 분리할 수 있어 메커닉적 흥미.
3. `kotobukiya_kuji` - 30연 시 S賞 1개 확정. 가챠 천장과 가장 비슷한 룰.
4. `happy_kuji` - 박스 비복원 + ラスト賞 1개. 一番くじ의 단순화 버전으로 비교 학습용.
5. `furyu_kuji` 또는 `bandai_online` - 디지털 즉시 추첨 패턴. 잔여 카운터 가시화가 시뮬레이터 UX와 잘 맞음.

상세 메커닉과 라인업은 `02_top_systems.md`와 `03_lineups.md`로 이어진다.
