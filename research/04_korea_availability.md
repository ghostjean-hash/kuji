### 1.4. "왜 단품 분할 판매가 주류인가"

1.4.1. 일본 발매가 끝난 라인업은 "박스가 풀리지 않는다." 한국 판매자가 일본 본토에서 박스 단위(일반 60~80매)로 매입한 후 한국 사용자가 원하는 등급만 사도록 분할 판매하면, 박스 매입가 + 마진 + 배송 + 환차로 가격이 자연스럽게 형성된다. [사실 / 추정 혼합]

1.4.2. 일본 정가 환산 vs 한국 단품 판매가 (라스트원賞 기준 일반 패턴)
- 일본 정가: 라스트원賞은 박스 마지막 1매 추첨 보너스로 별도 판매 가격 없음. 박스 매수가(60~80매 × 790~850엔 = 47,400~68,000엔) 이외 비용 0
- 한국 단품 시장가: 일본 발매 직후 30,000엔 → 약 30만 원 수준 [사실, 출처 검색 결과]
- 인기 IP / 고희소도일 경우 한국 시장에서 10배 이상 프리미엄 사례도 보고됨 [사실]

### 3.2. 핵심 발견 패턴

3.2.1. **이찌방쿠지가 가장 입수 친화적이다.** 정식 라인업이 아니어도 일본 직구·배대지·한국 단품 시장이 모두 활성화되어 있고, 한국 단품 시장(따빼몰 / 쿠지샵 / 코믹스아트 등)이 발매 1~3주 안에 등급별 단품을 내놓는다. 시뮬레이터의 검증 구매 라인업으로는 이찌방쿠지(루피 또는 드래곤볼)가 가장 현실적이다.

3.2.2. **코토부키야쿠지는 사실상 차단 상태.** 본사가 2019-11부터 해외 배대지 주문을 임의 취소하고 있어 한국 사용자가 일본 공식 채널로 직접 참여할 방법은 일본 거주 대리인을 거치는 것 외에 거의 없다. 단, 시뮬레이터의 "30연 S賞 확정" 차별 메커닉은 데이터 측면에서 가장 깔끔하게 공개되어 있어, 시뮬레이터 적용은 가능. 한국 사용자 검증 구매는 어렵다.

3.2.3. **Happy쿠지는 매장 한정으로 일본 직구 자체가 어려움.** 세븐일레븐·이토요카도·유메타운 매장에서만 발매되어, 한국에서 입수하려면 일본 구매대행을 통해 매장에서 직접 추첨해야 한다. 라인업 자체는 매력적이지만 검증 구매 비용이 상대적으로 높다.

3.2.4. **SEGA 럭키쿠지는 온라인 추첨 시스템이라 데이터 측면에서 시뮬레이터에 매력적이지만, 한국 사용자 직접 참여는 회원가입·결제 단계에서 차단될 가능성이 있다.** 한국 단품 시장은 캠페인 종료 후 등장.

3.2.5. **후류쿠지(미쿠)는 한국 단품 시장이 가장 안정적인 라인업 중 하나.** 코믹스아트·ASL Mall·피규어프레소·피규어팜 등 한국 호비샵이 후류 누들스토퍼 시리즈를 정기적으로 직수입한다. 다만 Citrus MIKU 자체의 일본 온라인 발매는 2026-04-10 종료되어 조사 시점에 이미 끝났고, 매장 잔여분은 일본 구매대행으로만 가능.

3.2.6. **한국 정가 패턴: 일본 정가의 약 1.5~1.9배.** 이찌방쿠지 한국 정가 12,000~15,000원 = 일본 790~850엔 환산 대비 약 1.5~1.9배.

3.2.7. **라스트원賞 / A상 단품 한국 시장 프리미엄 패턴: 인기 IP 30만 원+ / 일반 IP 10만 원~ / 인지도 낮은 IP 5만 원 이하.** 일본 발매 직후 일본 현지 시세 30,000엔 ≒ 한국 30만 원 수준이 일반 패턴. 인기 격화 시 한국 시장에서 10배 프리미엄도 보고됨.

## 4. 시뮬레이터 적용 권장

### 4.1. PWA 시뮬레이터에 한국 정보 노출 옵션 (의견)

4.1.1. **[의견] 라인업 화면에 "한국 입수" 배지 + 1줄 요약 표시 권장.**
- 예: "한국 입수: 일본 직구 + 한국 단품 시장 활발 (1.5~2배 가격, +1~3주)"
- 코토부키야 라인업의 경우 "한국 입수: 본사 차원 차단, 일본 거주 대리인 필요" 명시
- 사용자가 시뮬레이터로 가챠를 돌려보고 "이 등급을 한국에서 얼마에 살 수 있는지"를 즉시 파악 가능

4.1.2. **[의견] 등급별 단품 시장가 표시는 보류 권장.**
- 일본 발매 시점부터 한국 시장 가격이 매우 변동적 (일본 발매 +1주에 30만 원 → +1개월에 15만 원으로 하락하는 패턴 흔함)
- 시뮬레이터가 가격 데이터를 가지면 그 자체로 사용자 기대값을 왜곡할 수 있음
- 대신 "한국 단품 시장 검색 링크" (번개장터 / 따빼몰 / 코믹스아트 검색) 버튼을 제공하면 사용자가 즉시 현재 시세 확인 가능

4.1.3. **[의견] 한국 정식 발매 라인업과 미발매 라인업을 시각적으로 구분 권장.**
- 정식 발매: "한국 정식 발매 가능" 녹색 배지 + "1회 X,XXX원 / 발매일 / 매장 정보"
- 미발매 직구만: "직구만 가능" 노란색 배지
- 차단: "본사 차단" 빨간색 배지

### 4.2. 사용자 검증 구매 권장 채널

4.2.1. **이찌방쿠지 검증** (시뮬레이터 메커닉 검증용)
- 우선순위 1: 한국 정식 발매 라인업 (애니메이트 용산 / 홍대) - 시점차 거의 없음, 1회 12,000~15,000원
- 우선순위 2: 일본 직배송 가능 호비샵 AmiAmi - 박스 단위 일본 정가에 EMS 추가
- 우선순위 3: 일본 배대지 + 일본 본토 매장 구매대행 - 라스트원賞이 목적인 경우

4.2.2. **코토부키야쿠지 검증** - 일본 거주 지인 / 신뢰할 수 있는 일본 구매대행 한정. 30연 세트 구매는 약 25만 원 + 송료 + 대행료 = 약 35~40만 원 예상.

4.2.3. **나머지 4종(드래곤볼 / SEGA 주술회전 / Happy 픽사 / 후류 미쿠)** - 일본 구매대행이 가장 단순하고 신뢰성 높음.

### 4.3. 시뮬레이터 적용 전 보강 권장 항목

4.3.1. 한국 정식 발매 일정 데이터 소스 자동화: 제이엔케이인터마케팅 카카오 채널 / 인스타그램 피드를 매월 1회 수동 확인 → 시뮬레이터에 한국 발매일 / 한국 정가 / 한국 매장 노출

4.3.2. 한국 단품 시장가 추정값은 lineups.json에 기재하지 말 것 권장. 변동성이 높아 시뮬레이터 신뢰도를 깎음.

4.3.3. "한국 정식 발매 가능" 라벨은 라인업 단위가 아니라 IP × 시기 단위로 갱신 필요 (같은 IP라도 라인업마다 한국 정식 발매가 다름).
