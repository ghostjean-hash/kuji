# 3. 스코프 (in scope)

## 3.1. 통 (bin) 시각화

3.1.1. **격자 모델**: 박스 매수만큼 슬롯 격자 (드래곤볼 라인업 80 = 10열 × 8행). 비율은 추후 라인업별 종횡비 조정 가능 구조.
3.1.2. **잔여 / 뽑힘 상태**:
- 잔여 슬롯: 활성. 호버 / 탭 가능. 작은 복권 등 모티프.
- 뽑힌 슬롯: 회색 빈 자리. 비활성.
3.1.3. **셔플 배열 인덱스 매핑**: 슬롯 N개의 화면 위치 = 셔플 배열 인덱스 0~N-1. 사용자가 슬롯 클릭 → 해당 인덱스의 등급이 결과.
3.1.4. **시각 모티프**: 일본 쿠지 매장의 추첨함(クジ箱) 톤. 종이 / 골드 액센트.

## 3.2. 통 선택 인터랙션

3.2.1. **선택 흐름**: 인벤토리 N매 → "통에서 선택" 패널 진입 → 슬롯 1개 클릭 → splice(pickIndex) 결과 결정 → 페이지플립 reveal (M2 흐름 동일).
3.2.2. **반복**: N매면 N회 반복. 각 reveal 확인 후 다음 슬롯 선택 패널로 복귀.
3.2.3. **모션**:
- 호버: 슬롯 살짝 떠오름 + 골드 글로우.
- 클릭: 슬롯이 격자에서 빠져나와 페이지플립 카드로 변환되는 모션 (또는 슬롯 → 카드 매끄러운 전환).
- 빈 자리: 즉시 회색화.
3.2.4. **취소 / 변경**: 슬롯 클릭 후 reveal 시작 전까지 취소 불가 (PRNG 호출 = 결과 결정). 클릭 = 확정.

## 3.3. skip 체크박스

3.3.1. **구매 패널 내 체크박스**: "통에서 선택 건너뛰기" 라벨. 토글 즉시 다음 구매부터 적용.
3.3.2. **설정 탭 내 체크박스**: 전역 동일 토글. 구매 패널과 동기화.
3.3.3. **영속**: `kuji_settings_skip_pick` (boolean). localStorage. 기본값 false (= 통 선택 ON).
3.3.4. **skip ON 동작**: 슬롯 선택 패널 미진입. 인벤토리 N매가 곧바로 페이지플립 카드로 표시 (M2 흐름 그대로).
3.3.5. **첫 사용자 안내**: 처음 진입 시 통 선택이 무엇인지 1회 toast 또는 인라인 힌트 (사행성 표현 금지, 기능 설명만).

## 3.4. 결정론

3.4.1. **시드 + 회차로 셔플 배열 결정** (현행 5.3.2 그대로).
3.4.2. **추첨 = `splice(pickIndex)`**. skip ON 시 `splice(0)` (= 현행 head pop 동작).
3.4.3. **시나리오 6.5 (시드 검증)**: skip ON에서는 동일 시드 + 동일 회차 → 동일 추첨 순서 재현 (현행 보장 그대로).
3.4.4. **신규 시나리오 6.5.b**: skip OFF에서도 동일 시드 + 동일 회차 + 동일 슬롯 클릭 순서 → 동일 결과 재현.

## 3.5. 데이터 / 영속

3.5.1. **storage 신규 키**: `kuji_settings_skip_pick` (3.3.3).
3.5.2. **스키마 마이그레이션**: v2 → v3. 기존 사용자에게 `skip_pick = false` 초기화 + `schemaVersion = 3` 갱신. 박스 / 인벤토리 / 이력 보존.
3.5.3. **02_data 신규 절**: 1.12 통 선택 모션 상수 (격자 셀 크기 / 호버 글로우 / 클릭 → 카드 전환 시간 / 빈 자리 페이드).

## 3.6. M2 라이브 정정 학습 흡수 (단계 6 검증 룰 보강)

# 5. 성공 기준 (acceptance criteria)

5.1. **skip OFF 흐름**: buy(N) → 통 격자 표시 → N회 반복 (슬롯 클릭 → 페이지플립 reveal → 확인 → 격자 복귀) → 인벤토리 0 → 구매 씬 복귀.
5.2. **skip ON 흐름**: buy(N) → 통 격자 미표시 → 페이지플립 카드 곧바로 표시 → 확인 → 다음 (현행 M2 흐름과 동일).
5.3. **체크박스 동기화**: 구매 패널 토글 ↔ 설정 탭 토글 양방향 동기화. 새로고침 후에도 상태 유지.
5.4. **결정론 시나리오 6.5 (skip ON)**: 동일 시드 + 동일 회차 → 동일 추첨 순서 100% 재현.
5.5. **결정론 시나리오 6.5.b (skip OFF)**: 동일 시드 + 동일 회차 + 동일 슬롯 클릭 순서 → 동일 결과 100% 재현.
5.6. **격자 시각**: 잔여 슬롯 / 뽑힌 슬롯 시각 구분. 80슬롯 모바일 화면에서 터치 가능 (셀 ≥ 24px 권장).
5.7. **마이그레이션**: v2 사용자 → 첫 진입 시 v3 갱신 + skip_pick 기본 false. 박스 / 인벤토리 / 이력 보존.
5.8. **검증 룰**: 매직 넘버 0개 (src/ + tests/), core/ DOM import 0개, 사행성 표현 0건. M1/M2 모두 유지.
5.9. **단위 테스트**: `core/draw.drawOne(boxState, drawRng, LINEUP, pickIndex?)` 시그니처 변경 + skip ON/OFF 분기 + splice(pickIndex) 동작 테스트 추가.
