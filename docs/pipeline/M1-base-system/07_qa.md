# 1. QA 범위

7장 QA는 `01_spec.md` 6장 사용자 시나리오 + 7장 엣지 케이스를 정합 검증한다. 자비스는 (a) 시나리오 요구 요소가 코드에 1:1 정합하는지 정적 추적, (b) 엣지 케이스 처리 분기 존재 여부 정적 검증, (c) 사용자 직접 실행 권장 항목 정리 수행. 단위 테스트 100% pass는 사용자 브라우저에서 `tests/test.html` 실행 후 본 보고서 4장에 결과 추가 권장.
