## 4. 시뮬레이터 구현 시 주의점 / 시스템별 특수 룰

### 4.1. 공통 주의점

- **비복원 박스 모델**이 공통. 시뮬레이터의 핵심 자료구조는 「잔여 등급별 매수 카운터」. 매번 추첨 시 카운터에서 차감.
- **꽝 없음** 보장. 모든 추첨은 어떤 등급이든 반드시 당첨.
- **공식 등급별 매수 비공개** (一番くじ / Happyくじ / フリューくじ). 시뮬레이터는 인터넷 비공식 관찰값 (각 사이트, 매장 회수표 SNS 공유)을 차용해야 한다. 데이터 정확도에 한계 명시 필요.

### 4.2. 시스템별 특수 룰 (시뮬레이터 적용 포인트)

#### 4.2.1. 一番くじ
- Last One: 박스 마지막 1매 뽑을 때 "ラストワン賞 1개를 추가로" 지급. 시뮬레이터는 "현재 잔여 1매" 상태에서 추첨하면 결과 + ラストワン 둘 다 표시.
- Double Chance: 응모 시점이 구매 직후 (온라인) 또는 캠페인 종료까지 임의 시점 (매장). 시뮬레이터는 "쿠지 1매당 응모권 1매 발급 → 종료 후 추첨" 또는 단순화하여 "각 추첨마다 N% 확률 추가 당첨" 둘 중 하나로 모사.
- 일반적으로 Double Chance 당첨 수량 = 30~100개 / 전체 응모 수.

#### 4.2.2. SEGA 럭키쿠지
- Wラッキー賞: 응모는 매장 쿠지 회수권 회수 → 응모엽서 또는 온라인 응모. 일반적으로 발매 종료 후 추첨. 일관된 룰로 단순화 가능.
- 송료 룰 (온라인): 첫 구매 시만 660엔 송료. 시뮬레이터는 "1번째 추첨에만 송료 가산" 옵션 제공 가능.

#### 4.2.3. Happyくじ
- 단일 ラスト賞만 존재. Double Chance는 라인업별 상이 (PIXAR 2026 기준 ハッピーチャレンジ 캠페인 별도 운영).
- 라스트원 룰을 가장 단순하게 모사할 수 있는 시스템.

#### 4.2.4. コトブキヤくじ
- **시뮬레이터의 차별점**. 30연 세트 구매 시 S賞 1개 확정.
- 구현: 사용자가 "1회 / 10연 / 30연" 선택 → 30연 선택 시 S賞 1매를 강제 슬롯에 배정 → 나머지 29회는 통상 추첨.
- 박스 카운터는 1매 단위 차감이지만, 30연이 S賞을 1매 점유하므로 실효 박스에서 S賞 잔여를 1 차감.
- ラストワン / Double Chance 없음.

#### 4.2.5. フリューくじ
- 라인업별 룰 다양성이 큼. 시뮬레이터는 "기본 ラスト賞 + Wチャンス"의 변형으로 모사하되, 라인업 데이터에 룰 플래그를 별도 표기 필요.

### 4.3. 시뮬레이터 구현 권장 우선순위

[의견] 메커닉 다양성을 학습 / 체험 가치로 보면 다음 순서를 권장:

1. `ichiban_kuji` - 표준 룰 (Last One + Double Chance) 모듈. 다른 시스템의 베이스.
2. `kotobukiya_kuji` - 30연 S賞 확정 룰. 가챠 천장과 가장 비슷.
3. `sega_lucky` - Wラッキー賞 (응모식 추가 추첨). 메커닉적 차이 분명.
4. `happy_kuji` - ラスト賞만 있는 단순 변형. 학습용 소품.
5. `furyu_kuji` - 라인업 다양성 학습용. 4번 이후로 우선순위 낮음.
