# 2. 모순 (contradiction)

## 2.1. C-1. 슬롯 수와 셔플 배열 길이의 인덱스 매핑 모순

| 항목 | 값 |
|---|---|
| ID | C-1 |
| 위치 | 01_spec 5.14.2.1 / 5.14.2.2 vs 5.3.2 / 5.4.4 |
| 등급 | 모순 (높음, 결정론 정합 핵심) |

설명:
- 5.14.2.1: `rows = Math.ceil(BOX_SIZE / cols)`. 드래곤볼 80 = 10×8. **슬롯 80개**.
- 5.14.2.2: "슬롯 수 = 박스 매수 (`BOX_SIZE`). 셔플 배열 인덱스 0 ~ N-1 매핑." → N = 80.
- 5.3.2: "`BOX_SIZE - 1` 매 (Last One 제외)의 등급 라벨 배열 셔플". → **셔플 배열 길이 = BOX_SIZE - 1 = 79**.
- 5.4.4: "79매 셔플 + 마지막 1매 추첨 시 Last One 자동 지급".
- 5.14.4.2: 사용자 슬롯 클릭 → `drawOne(boxState, drawRng, LINEUP, pickIndex)` 호출 → `splice(pickIndex)`.

결과: 슬롯 80개에 대해 `pickIndex` 가 0~79 범위가 되면 셔플 배열(길이 79)에서 `splice(79)` 는 빈 배열을 반환하거나 정의되지 않는 동작 발생. Last One 슬롯이 별도 슬롯인지 / 일반 슬롯의 마지막 1매 클릭 시 자동 Last One 지급인지 명시되지 않음.

영향: 5.7 결정론 보장 / 5.14 통 선택 핵심 메커닉의 인덱스 매핑이 미정의. 5.4 Last One 자동 지급 흐름과 5.14 격자 슬롯 수의 정합 불가.

권고:
- 5.14.2.2를 명확화: "슬롯 수 = 셔플 배열 길이 = `BOX_SIZE - 1` (Last One 제외)". 격자 셀 수도 79로 변경 (드래곤볼 79 = 10×8 마지막 행 9개) 또는
- 슬롯 80개 유지하면서 Last One 슬롯을 별도 표시 (예: 마지막 슬롯 = 골드 색 / 클릭 불가 / 일반 슬롯 79개 모두 뽑힌 시점에 자동 지급) 명시.
- 5.14.2.1 "드래곤볼 80 = 10×8" 예시도 동일하게 정정.
